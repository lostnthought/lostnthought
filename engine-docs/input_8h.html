Receives input from SDL in a while loop, pushes th events onto queues to be consumed at the end of the rendering frame.

Also processes keyboard events.

Parameters

event_queueThe queue for SDL_Events that are not keyboard events that must be consumed once every render frame. For Nuklear.
event_queue_countThe queue count for SDL.
sdl_queueThe queue for SDL_Events that are not keyboard events that must be consumed once every render frame.
